## Overview

Centralized cloud SaaS architectures force users to rent their digital cognition while sending personal and proprietary data to third-party datacenters.

The **Sovereign AI Blueprint** represents an inversion of this paradigm. It serves as the common architectural spine and unified desktop launcher for local-first intelligence applications, enabling private, air-gapped operations where you own your models, your vector memory, and your insights.

---

## The 6-Layer Intelligence Stack

The blueprint standardizes multi-agent coordination across six specialized layers:

1. **Reception (Layer 1):** FastAPI entry point validating incoming user queries and payload security.
2. **Agent Router (Layer 2):** Dynamic intelligence switch that routes tasks between offline local inference (via Ollama) and scalable cloud endpoints (via Gemini API) based on resource availability and privacy settings.
3. **Prompt Schematization (Layer 3):** Strict schema enforcement, domain constraint injection, and tone guardrails.
4. **RAG 2.0 Pipeline (Layer 4):** Dense + sparse hybrid vector search (FAISS + BM25) coupled with neural re-ranking for ultra-precise context grounding.
5. **Session Memory (Layer 5):** Short-term and long-term state management preventing conversational drift and cross-view discrepancy.
6. **Consistency Logic (Layer 6):** Cross-subsystem integrity checks ensuring that strategic plans, analytical insights, and conversational outputs maintain narrative harmony.

---

## Infrastructure Highlights

- **Air-Gapped Privacy:** Zero outgoing telemetry when running in local-only mode; fully compliant with stringent privacy and data sovereignty requirements.
- **Robust Process Management:** Embedded process supervisor managing subprocess PIDs, health checks, graceful restarts, and memory leak mitigation.
- **Model Context Protocol (MCP) Integration:** Enables seamless interoperability between local tools and host IDEs or agentic companions.

---

## Tech Stack

- **Core:** Docker, uvicorn, Python, FastAPI, SQLite Edge Storage.
- **Inference & Orchestration:** Ollama, Google AI Studio (Gemini), ProcessManager, MCP Servers.
